# STEPi 다음 작업 결과 (2026-10-24)

## 이번에 실제 수정한 기능
- TypeScript 빌드 오류 6개 수정 상태 유지
- 학생 추가/수정 Mock 데이터 localStorage 유지 (새로고침 후에도 보존)
- 문제 JSON 파일 유효성 검사 및 로컬 목록 등록; 문제 목록 탭에 반영
- 학생 검색 대소문자 무관 처리
- 조회 기간별 결정적 데모 활동량 계산 (임의 실제 데이터로 오해하지 않도록 샘플 명시)
- 데모 데이터 초기화 버튼 추가

## 문제 JSON 예시
```json
[{"id":"P0100","text":"2x+3=7을 푸시오.","unit":"문자와 식","difficulty":"하","active":true}]
```

## 10주차 완료 전 남은 항목
- 현재 16개 화면은 대부분 레거시 HTML 문자열을 React 안에 렌더링하는 방식임. 순수 React 컴포넌트 전환은 미완료.
- 일부 차트/통계는 고정 샘플 수치임. 백엔드 응답 계약 확정 후 데이터 매핑 필요.
- 로그인, 리포트 PDF, 관리자 기준 데이터 CRUD는 실제 API 미확정 또는 서버 기능 부재로 데모/인쇄 대체임.
- AI①·AI② 내부 API는 프론트에서 직접 호출하지 않음. 백엔드 웹 API 확정 후 연결.
- 실제 브라우저에서 각 버튼·탭·필터 회귀 테스트 필요.

## 실행
`npm.cmd install` → `npm.cmd run build` → `npm.cmd run dev`
