1. `/dashboard/summary` 및 기간/학생별 통계의 파라미터와 응답 스키마
2. 학생 등록·수정 API 존재 여부 및 권한, ID/학년·반 필드 규격
3. 학생/반/기간 리포트 목록, PDF 생성·다운로드 API
4. 문제·개념·Skill 관리자 CRUD 경로 및 request/response 예시
5. AI 분석 결과/튜터 기록의 프론트용 응답 스키마와 페이징
