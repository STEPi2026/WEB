# STEPi 백엔드 연동 전 최종 확인

## 현재 검증 범위
- 사용자가 Mock 모드에서 기본 기능 15개와 추가 6개 테스트 통과를 보고함.
- 직전 프로젝트 버전은 사용자 컴퓨터에서 `npm.cmd run build` 성공을 확인함.
- **이 ZIP의 빌드는 별도로 확인해야 함.** 실제 백엔드 API 호출, 서버 응답, 권한 정책은 검증되지 않음.
- 백엔드 v0.3의 119개 API는 협의용 후보이며 구현 확정 목록이 아님. AI①·AI② 내부 API는 웹에서 직접 호출하지 않음.

## 프론트엔드에서 준비된 API 진입점
- `src/api/client.ts`: Axios baseURL, bearer access token, API 호출 래퍼.
- `.env.example`: Mock/서버 모드와 baseURL 예시.
- `src/legacy/pages.ts`: 상당수 화면이 샘플 데이터를 렌더링함.
- 실제 API 모드에서 전체 화면의 응답 매핑·로딩·빈 상태·401/403/500 동작이 완성된 것은 **아님**. 이 작업은 서버 계약 확정 후 필요함.

## 팀에 확정 요청할 사항
1. 웹에서 호출 가능한 API 목록과 실제 구현 완료 여부
2. 개발/배포 BASE_URL, CORS 허용 Origin, 인증 쿠키 또는 Bearer 정책
3. 로그인/토큰 갱신/만료/로그아웃 요청·응답 예시
4. 학생 생성·수정·삭제 API 및 권한, 학생 목록 페이징 구조
5. 대시보드·오류 분석·AI Tutor·리포트 응답 JSON 예시 및 날짜 필터 파라미터
6. 문제/개념/Skill 관리의 생성·수정·삭제 API와 유효성 오류 구조
7. AI①·AI② 결과의 백엔드 전달 형식, 비동기 상태/실패 처리

## 로컬 최종 확인
1. 프로젝트 폴더(`package.json` 있는 곳)에서 `npm.cmd install`, `npm.cmd run build`, `npm.cmd run dev`
2. 로그인/회원가입과 사이드바의 공식 STEPi 로고가 찌그러지지 않고 보이는지 확인
3. 16개 화면 전환, 21개 기존 Mock 테스트 재실행(로고 변경으로 회귀 없는지)
4. F12 Console 오류 없음 확인, 브라우저 새로고침 및 다운로드 검사
5. **실제 서버 연결은 백엔드 명세 확정 후 별도 통합 테스트 필요**
