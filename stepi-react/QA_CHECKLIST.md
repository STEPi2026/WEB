# STEPi 10주차 기능 검증 체크리스트

## 확인된 코드 구현 범위
- 로그인/회원가입 데모, 메뉴 및 상세 화면 이동
- 학생 검색/상세/추가/수정, 로컬 저장 및 초기화
- 기간/학생 선택 시 데모 풀이 집계와 분석 표 갱신
- 문제 개별 등록/JSON 일괄 등록/상태 변경/삭제
- 기준 데이터(개념/Skill/오개념) 추가/상태 변경/삭제
- 리포트 상세 이동, 브라우저 인쇄(PDF로 저장 가능), 학생 CSV
- Axios API 어댑터, Mock 토글 및 미확정 API 분리

## 브라우저에서 반드시 직접 검사할 항목
1. npm.cmd install → npm.cmd run build → npm.cmd run dev
2. 로그인 데모 → 사이드바 10개 메뉴 및 6개 상세 화면 이동
3. 학생 검색/추가/수정 → 새로고침 후 유지 → 초기화
4. 학습 현황 기간 변경 시 풀이 수 변경
5. 오류·오개념 분석 날짜/학생 선택 시 표의 발생 횟수 변경
6. 문제 등록/일괄 등록/삭제, 기준 데이터 추가/삭제
7. 리포트 인쇄(PDF 저장) 및 CSV 내려받기
8. 화면 크기별 레이아웃 및 브라우저 개발자 도구 오류 확인

## 미완료 / 협의 필요
- 실제 AI①·AI② 응답 구조 및 OCR 이미지 처리
- 인증 JWT/refresh 응답, 역할 권한 및 보호 경로
- 전체 통계, 오류 유형, 리포트, 게임화 등 실제 데이터 조회 계약
- 학생 생성/수정 등 관리자 API 최종 경로 및 응답 스키마
- 차트 일부는 예시 시각화이며 실제 학습 기록을 의미하지 않음
- 전 화면의 접근성/브라우저 E2E 테스트는 미실시

**주의:** 빌드 성공만으로 모든 프론트 기능 완료 또는 실제 API 연동 가능성을 보증하지 않습니다.
